# 海外项目数据库

面向中国大陆申请人的海外工作 / 实习 / 毕业后工签项目数据库。每条资格判定都追到一个官方 URL，并标注核实日期。

- 站点：https://eddieye1004.github.io/overseas-program-dataset/
- 数据与源码：https://github.com/eddieye1004/overseas-program-dataset

这个仓库只做一件事：让 `https://eddieye1004.github.io/robots.txt` 存在。
GitHub Pages 的 robots.txt 只能从 host 根路径提供，而主站是项目子路径站点，
拿不到 `/robots.txt` 这个位置，所以单独开一个 `<用户名>.github.io` 仓库放它。

内容见 [robots.txt](robots.txt)。
